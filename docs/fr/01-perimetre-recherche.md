# 01 — Périmètre de la recherche

Ce dépôt rassemble des notes techniques sur la propriété numérique, les preuves à divulgation nulle de connaissance, l’exécution confidentielle, Base et HyperEVM. Le code de référence se trouve dans prototype/ ; les textes décrivent ses mécanismes sans présenter le dépôt comme un audit ni comme une preuve de préparation en production.

La méthode consiste à relier chaque affirmation à un fichier lisible, à séparer garanties cryptographiques, hypothèses opérationnelles et politiques applicatives, puis à noter les modes d’échec.
